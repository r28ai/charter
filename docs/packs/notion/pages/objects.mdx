| Field | Type | Description |

| `icon` | [Icon](#icon) | The page's icon. |
| `cover` | [Cover](#cover) | The page's cover image. |
| `children` | [Block](#block)[] | The content of the new page, as blocks. At most 100, and at most two levels of nesting — append the rest afterwards. <span className="field-constraints">max 100 items</span> |
| `content` | [Block](#block)[] | An alias for `children`. Send one or the other, not both. <span className="field-constraints">max 100 items</span> |
| `markdown` | `string` | The content of the new page as Notion-flavored Markdown, which Notion parses into blocks. Newlines must be `\n`. |
| `template` | [Template](#template) | A template to build the page from. Applying one is incompatible with supplying content directly. |
| `position` | [Position](#position) | Where the content is placed within the page. |
| `allowAsync` | `boolean` | Whether a large `markdown` body may be parsed in the background. When true the call answers 202 with an async task to poll rather than the finished page. |
