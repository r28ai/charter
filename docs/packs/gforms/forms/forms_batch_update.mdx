Each request sets exactly one kind of edit, one of update_form_info, update_settings, create_item, move_item, delete_item or update_item, and they apply in order, atomically. Items are addressed by index, and indices shift as the batch applies: inserting at index 2 moves every later item down, so order several insertions back-to-front or state each location against the form as it will be by then."
