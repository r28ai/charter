| `query` <span className="required" title="required">*</span> | `string` | Search query to execute. |
| `searchDepth` | [SearchDepth](/packs/tavily/search/objects#searchdepth) | Latency/relevance tradeoff. The server applies `basic` when this is absent. `advanced` costs 2 credits; `basic`, `fast` and `ultra-fast` cost 1 credit. |

Available only when `search_depth` is `advanced`, `basic` or `fast`. Each chunk is at most 500 characters and joined with `[...]`. <span className="field-constraints">≥ 1; ≤ 3</span> |
| `maxResults` | `integer` | Maximum search results to return. The server applies 10 when this is absent. <span className="field-constraints">≥ 0; ≤ 20</span> |

| `timeRange` | [TimeRange](/packs/tavily/search/objects#timerange) | Filter by publish or last-updated date window. |
| `startDate` | `string` | Return results after this date (`YYYY-MM-DD`). |
| `endDate` | `string` | Return results before this date (`YYYY-MM-DD`). |
| `includePublishedDate` | `boolean` | Include `published_date` on each result. Beta feature. Automatically enabled when `topic` is `news`. |
| `filterByPublishedDate` | `boolean` | Remove results outside the date window or with no detectable date. Also enables `include_published_date`. |
| `includeAnswer` | `boolean` \| [ExtractDepth](/packs/tavily/search/objects#extractdepth) | Include an LLM-generated answer. `true` or `basic` returns a quick answer; `advanced` returns a detailed answer. The server applies `false` when this is absent. |

| `includeImageDescriptions` | `boolean` | Add descriptive text per image when `include_images` is true. |

| `includeDomains` | `string`[] | Domains to include (max 300). <span className="field-constraints">max 300 items</span> |
| `excludeDomains` | `string`[] | Domains to exclude (max 150). <span className="field-constraints">max 150 items</span> |
| `includeDomainsMode` | [IncludeDomainsMode](/packs/tavily/search/objects#includedomainsmode) | How `include_domains` is applied. Requires `include_domains` to be set. |
| `country` | [Country](/packs/tavily/search/objects#country) | Boost results from a country using Tavily's lowercase English country name (for example `united states`). Available only when `topic` is `general`. |

| `filterByLanguage` | `boolean` | Strictly filter out non-matching languages. Requires `language`. |
| `autoParameters` | `boolean` | Let Tavily configure parameters from the query. Explicit values override auto-selected ones. `include_answer`, `include_raw_content` and `max_results` must always be set manually when using this. |
| `exactMatch` | `boolean` | Return only results containing the exact quoted phrase(s) in the query. |
| `includeUsage` | `boolean` | Include credit usage in the response. |
| `safeSearch` | `boolean` | Filter adult or unsafe content. Not supported when `search_depth` is `fast` or `ultra-fast`. |
