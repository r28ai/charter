## Body

<div className="reference-table">

| Field | Type | Description |
| --- | --- | --- |
| `url` <span className="required" title="required">*</span> | `string` | The base URL to start crawling from |
| `prompt` | `string` | Natural language prompt to generate crawler options from. |
| `excludePaths` | `string`[] | URL pathname regex patterns that exclude matching URLs from the crawl. <span className="field-constraints">max 1000 items</span> |
| `includePaths` | `string`[] | URL pathname regex patterns that include matching URLs in the crawl. <span className="field-constraints">max 1000 items</span> |
| `maxDiscoveryDepth` | `integer` | Maximum depth to crawl based on discovery order. |
| `sitemap` | `"skip" \| "include" \| "only"` | Sitemap mode when crawling. The server applies 'include' when this is absent. |
| `ignoreQueryParameters` | `boolean` | Do not re-scrape the same path with different query parameters. |
| `regexOnFullURL` | `boolean` | Match includePaths and excludePaths against the full URL instead of just the pathname. |
| `limit` | `integer` | Maximum number of pages to crawl. The server applies 10000 when this is absent. |
| `crawlEntireDomain` | `boolean` | Allow the crawler to follow internal links to sibling or parent URLs, not just child paths. |
| `allowExternalLinks` | `boolean` | Allow the crawler to follow links to external websites (one hop only). |
| `allowSubdomains` | `boolean` | Allow the crawler to follow links to subdomains of the main domain. |
| `ignoreRobotsTxt` | `boolean` | Ignore the website's robots.txt rules. Enterprise only. |
| `robotsUserAgent` | `string` | Custom User-Agent string for robots.txt evaluation. Enterprise only. |
| `delay` | `number` | Delay in seconds between scrapes. Setting this forces concurrency to 1. |
| `maxConcurrency` | `integer` | Maximum number of concurrent scrapes for this crawl. |
| `webhook` | [Webhook](/packs/firecrawl/batch/objects#webhook) | Webhook specification for crawl lifecycle events. |
| `scrapeOptions` | [ScrapeOptionsNested](/packs/firecrawl/search/objects#scrapeoptionsnested) | Options applied when scraping each crawled page. |
| `zeroDataRetention` | `boolean` | If true, this will enable zero data retention for this crawl. |
