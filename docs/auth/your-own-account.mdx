Every pack needs one credential before its first call, and every service issues
it somewhere different. This table names the place: the link opens it in a new
tab, so this page stays where you left it.

Most packs take an API key, which is a minute's work and needs nothing more —
[API keys](/auth/api-key-tool-factory) covers what Charter does with one. Google,
Slack, GitHub and Notion each have a guide, because each wants something
registered before it will issue a credential, and Google's takes ten minutes of
console screens that are much easier with pictures.

Set the variable and the pack reads it on its next call: no
[`configure()`](/reference/configuration#configure), no restart. The order a
pack checks them in is on
[environment fallbacks](/reference/configuration#environment-fallbacks).

## Your users' accounts

Everything above connects **one** account — yours — to a script, an agent or an
MCP server you run. A product where each user connects their own needs more: a
consent route inside your app, a grant per user, and somewhere to keep them.
The console steps are the same, so do the guide first, then
[getting the grant](/auth/oauth-flow) and
[serving many users](/auth/authorization-servers#serving-many-users).
