```text Agent prompt
Set me up to use Charter. Fetch https://docs.r28.ai/charter/agent-setup/prompt.md and follow it.
```

Paste that into Claude Code, Cursor, Codex, or any agent that can fetch a URL. It installs Charter, adds the skill that teaches the agent to write packs, and points it at these docs. [The instructions](/agent-setup/prompt.md) are served as plain text, so you can read exactly what your agent will read before it runs anything.
